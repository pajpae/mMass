##

Changes made to the program:  
1. Fixed a problem not correctly repainting the spectrum viewer canvas.
2. Fixed problems in both the parsers for reading .mzxml and .mgf input.
3. Added the possibility of manually appending peptide sequences to peaks in the peaklist using the peak editor. This also added the possibility to show the sequences in the peaklist table in a respective column.
4. Added a function to read .csv and .xml result files generated after Mascot PMF search and appending the peptide sequences to the peaks that were able to be matched.

Changes made to mMass can be tracked in the branch private_testing, which we used for this project.
##

Instructions for result reading:  

After a peaklist was generated by either inputing a .mgf file or using the peakpicking processing option on a spectrum perform a Mascot PMF search with the peaklist. This will have to be done externally as the code here is no longer able to use the Mascot search integration. From the results of the PMF search generate a .csv or .xml results file by selecting "format as: **export results**" above the list of potential hits. In this export include the peptide match information.  
With the results exported select "Tools: Read Mascot Results" from the mMass toolbar. Choose the exported results file as input. Now the programm will match the matched peaks to those present in the open document and append the peptide sequences in the peaklist table. Make sure to have the table actually show the column for peptide sequences by right-clicking and selecting the "pep seq" option.
The folder showcase_data contains a .mgf file and a .mzxml file and results files (both .csv and .xml) exported from these, which may be used as example data.
